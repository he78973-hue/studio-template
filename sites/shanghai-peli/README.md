# 沿水而生 · 小鹈走过上海

横向滚动的上海历史图版页。十张时代插画挂在深色展厅墙上，每页有一只对应时代的像素小鹈住在图版里：翻页时它从画面左缘走入，沿地面/水面一直走到画面右侧站定；每页下方自动出现一条带出处的历史注记。页面本身是可交互的静态网站，可自行录屏；`preview/` 下的独立 PNG/MP4 仅用于 Studio 模板库展示，不是网站运行依赖。

## 运行

在仓库根目录运行（无 npm 依赖，也无构建步骤）：

```sh
python3 -m http.server 8128 --bind 127.0.0.1 --directory sites/shanghai-peli
```

打开 <http://127.0.0.1:8128/>。直接双击 `index.html` 也能看，但本地服务器能保证懒加载与相对资源路径一致。

## 操作

| 操作 | 行为 |
|---|---|
| 垂直滚轮 | 前进 / 后退一章（累计 40px 触发，720ms 锁，防惯性跳页） |
| 横向滚轮 / 触控板 / 触摸 | 原生横向滚动 |
| 鼠标按住拖动 | 临时关闭 scroll-snap，松手吸附到最近一章 |
| `←` `→` / `PageUp` `PageDown` / `Home` `End` | 上一章 / 下一章 / 首尾 |
| 底部年份圆点 | 跳转章节 |
| 翻页后 | 该页小鹈从画面左缘沿地面走入；下方“小鹈注”自动出现，无需点击 |
| 右上“史料” | 打开资料来源与史实说明 |
| 末页 `↺` | 回到封面 |

## 素材来源

- 图版：`shanghai-timeline-png-svg.zip`，按原文件复制，未改绘、未裁切。
- 小鹈：`shanghai-pixel-birds-png-svg.zip`，使用其中的 SVG 版本；`shape-rendering="crispEdges"` 保持像素边缘。
- 图标：Lucide（ISC）路径，统一规格后放入 `icons.js`；没有在页面里另写第二套图标。
- 品牌图标：`assets/brand-peli-shanghai.svg`，32×32 像素网格，小鹈、东方明珠式塔身与水岸黄绿/青/紫配色。

## 动效预算

- 常规反馈约 180–220ms：导航箭头悬停位移、章节计数 tick、注记淡入、资料弹层 220ms 淡入。
- 签名动效只有小鹈走入：翻页后从画面左缘外起步，沿地面线性横穿整幅画面，一直走到右侧 89% 的位置，历时 3s；同时做 6 次 500ms 的步态起伏，走完站定，不再悬空或持续上下浮动。
- 鸟的进场由 `.scene` 的 `overflow:hidden` 裁切，看起来是从图版左缘走出来；横向落点统一在右侧 89%，每页只用 `--by` 调整站立高度，随图版缩放。手机上小鹈不超过图版宽度的 20%，避免走到右侧时被裁切。
- 时长统一为 `--motion-quick/fast/base/slow/gait/walk` 和 `--ease/--ease-in-out`；不在各处散写秒数。
- 进度线用 `transform: scaleX()` 而不是宽度动画，避免布局抖动。
- 打开史料弹层或页面进入后台时暂停小鹈行走；减少动效模式下直接关闭行走/步态，让鸟停在最终位置，而不只是把时长压到 0.01ms。
- 跨 3 页以上的跳转（如末页重来）直接落位，避免长距离飞页把所有计数动画快速刷一遍。
- `prefers-reduced-motion: reduce` 下停止行走/步态，并压缩所有过渡。

- 本次校验命令、媒体解码、浏览器播放/跳转与环境接入边界记录在 [VERIFICATION.md](./VERIFICATION.md)。

## 录制建议

- 桌面 1440×900 或 1920×1080；浏览器全屏，隐藏书签栏。图版按高度自适应，两种比例都不会裁掉上下内容。
- 从封面开始，滚轮或 `→` 逐页推进；每页停 5–7 秒，留出 3 秒的完整走入。小鹈走到画面右侧后自动停住，下方“小鹈注”无需点击即可读到。
- 需要纯画面时，录屏时把鼠标移到屏幕外；底部导航与右上计数会保留，作为时间轴。
- 手机 390×844 下图版下方会出现可读图注，适合竖屏短片；`Screen` 录制时建议先滚动到目标页再录。

## 无障碍与边界

- 每张图版有替代文本和图注；页标题在 DOM 中，不依赖图内文字被读出。
- 图标按钮均有 `aria-label`；纯装饰图标 `aria-hidden`；时间轴圆点带 `aria-current="step"`。
- 资料弹层使用原生 `<dialog>`，支持焦点约束、`Esc` 与遮罩点击关闭；打开时方向键不会翻动背景。
- 尊重 `prefers-reduced-motion`；章节不自动翻页，无声音。唯一外部运行资源是 Google Fonts（DM Mono、Noto Sans SC、Noto Serif SC）；不可达时回退到系统字体，字形可能不同。
- 纯静态文化叙事模板，无后端、账号、数据采集或导出服务。图片内文字已烘焙，改写内容需同步替换图版与可访问 HTML 图注；地图并非精确历史地形。
- `catalog.json` 以 `shanghai-peli` 登记，归入 `creative`、使用 `ink` 配色；不提供未经部署验证的公网 `previewUrl`。PR 合并后仍需 Studio 环境负责人选择已合并固定 SHA，不能把提交 PR 当作自动上架。
- 许可与来源见 [CREDITS.md](./CREDITS.md)，完整 Lucide ISC / Feather MIT 许可见 [licenses/lucide-LICENSE.txt](./licenses/lucide-LICENSE.txt)。应用代码与用户提供图版未附单独许可，不额外承诺无限制商用。

## 史实口径

- “六千年”指上海地区的人类活动史。崧泽遗址博物馆展示距今约 5500 年的墓地；不是六千年建城史。
- 751 年华亭县、1267 年上海镇、1292 年上海县，依据上海市统计局《上海建城》。
- 1843 年开埠发生在鸦片战争及不平等条约之后；图版把租界起划与旧城并置，不把开埠写成单纯的繁荣。
- 1958 年江苏十县分两批划入：1 月上海、嘉定、宝山；11 月松江、川沙、南汇、奉贤、金山、青浦、崇明。扩大的是行政版图。
- 1990 年 4 月宣布浦东开发开放；桥梁、地铁与天际线是此后多年逐步形成的。
- 图版中的河道与地图是艺术化示意，不是历史地形复原。
