# 一句话方向

把菜单变成一张有食欲的餐桌：点开一道菜，展开它的食材小票。

## 复制即用

为「超级沙拉」做一个清新、有食欲的餐饮网站。用深叶绿、柑橘橙和奶油白，大字标题搭配真实食物摄影。九款餐品像摆在餐桌上一样散铺，悬停点亮；点击后餐盘从原位放大，旁边展开列有食材、酱汁、过敏原和价格的小票。支持分类筛选、购物袋、数量修改、本地保存和订单预览。统一动效节奏，快速操作可打断；手机双列，兼容键盘与减少动态效果。使用可替换的本地图片，保留来源和许可说明，交付可直接运行的静态网站。

## 换个品牌也能用

- 把「超级沙拉」换成你的餐饮品牌，把九款餐品替换为真实菜单。
- 保留“餐桌陈列 → 餐盘放大 → 食材小票”的体验结构，配色和摄影随品牌调整。
- 菜名、价格、配料和过敏原以你提供的资料为准；没有真实数据时明确标注演示内容。
- 默认只做本地订单预览。真实支付、库存和门店下单需另行接入。
- 图片授权按具体素材核实；该案例的许可记录见 `source/assets/ASSETS.md`，不能把整个素材包视为无限制商用。
