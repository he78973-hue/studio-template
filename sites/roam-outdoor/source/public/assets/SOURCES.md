# ROAM asset sources

ROAM is a fictional concept brand. The merchandise photographs below are third-party reference assets, not ROAM-owned photography or evidence of an association with the pictured brands. The public source URLs do not establish an open redistribution license. No commercial-use or unrestricted-reuse permission is asserted for these images; replace them with owned or appropriately licensed merchandise photography for a commercial storefront.

Images were background-removed, tightly cropped and encoded as WebP. Blue/pink fabric was recolored for the concept, retaining seams and shading; neutral variants can additionally use a CSS grayscale filter. Original downloads and working contact sheets are not included.

## Fonts

Fonts are locally hosted, unmodified font programs; filenames are deployment aliases. Full SIL OFL 1.1 notices are in the template's `licenses/` directory.

- `fonts/brand.woff2`: [Barlow Condensed, Latin 800 italic](https://cdn.jsdelivr.net/npm/@fontsource/barlow-condensed/files/barlow-condensed-latin-800-italic.woff2).
- `fonts/sans.woff2`: [Manrope variable, Latin](https://cdn.jsdelivr.net/npm/@fontsource-variable/manrope/files/manrope-latin-wght-normal.woff2).
- `fonts/mono.woff2`: [PT Mono, Latin 400 normal](https://cdn.jsdelivr.net/npm/@fontsource/pt-mono/files/pt-mono-latin-400-normal.woff2).

React / React DOM / Scheduler are MIT; Lucide is ISC with Feather-derived MIT content. Full runtime-dependency notices accompany the template. The complete application has no separately assigned open-source license; dependency licenses do not license the merchandise photographs or the whole template.
