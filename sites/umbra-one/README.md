# UMBRA ONE — 黑白液态玻璃落地页

单文件产品发布页；虚构的端侧 AI 计算终端。保留黑白灰玻璃、工程栅格、Gloock 刊头、Crimson Pro 斜体及上亮下暗的点阵页脚。不使用 Skillry 的付费模板代码或素材包；视觉方向参考其公开的液态玻璃落地页介绍。

## 启动与运行依赖

直接打开 `index.html`，或在仓库根目录执行：

```sh
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/sites/umbra-one/
```

无需 npm、打包步骤、外部 API、CDN 或环境变量。CSS、JavaScript、图表和四个字体家族均内嵌；入口即交付文件。预览素材不参与网站运行。

## 可交互内容

- 候补表单：浏览器邮箱格式校验、页内确认；不发送或保存输入。
- Core / Pro 配置切换、整付 / 12 期演示价格切换。
- FAQ 原生折叠面板、可手动切换的评语轮播。
- 模拟终端输出、吞吐图表、倒计时和渐变点阵字标。
- 漂移白光、玻璃指针高光、细微倾转；系统减弱动态偏好下关闭装饰运动。

## 演示边界和已知限制

- UMBRA ONE、产品能力、价格、库存、规格、评语、版本和地理标记都是虚构内容，不是经测量的硬件承诺或真实客户反馈。上生产前必须替换。
- 候补/预订按钮只是锚点与表单演示，没有邮件、账号、支付或硬件接口。
- 倒计时每次加载重置为约 9 天 7 小时，不是真实销售截止日期。
- Pro 分期前 11 期 ¥2,483.33，末期 ¥2,483.37，合计 ¥29,800；仅作界面展示。
- 图表与终端数据为本地模拟。轮播默认自动切换，手动选择后停止；减弱动态时不自动切换。
- 模糊与 `backdrop-filter` 的效果因浏览器而异；不支持时保留半透明面板。中文使用本机苹方/宋体等回退字体；点阵以本机 Helvetica/Arial 栅格化，跨系统字形可能不同。
- 页面面向视觉展示，低对比度装饰文字与自动轮播未作完整 WCAG 合规认证。未验证原生 App、实际推理能力或邮件发送。
